# How escrow works, simply

Start here · 4 min · External references checked 2026-09-12.

Escrow gives both sides a clear order of events: agree, set funds aside, complete the work, then decide what happens next.

## 1. Agree first

The buyer and seller review the description, amount, deadline, acceptance checks and refund or dispute options.

## 2. Set funds aside

In a real service, the agreed money stays separate while the work is completed. In this sandbox, the balance is only a demonstration.

## 3. Do the work

The seller delivers the item or service and adds the evidence the agreement asks for.

## 4. Review the result

The buyer checks the delivery against the agreed list and can accept it, request a remedy or ask for help.

## 5. Finish the deal

A permitted decision releases the seller payment, returns money to the buyer or keeps the disputed part on hold.

## Important limitation

This website is an interactive sandbox. Balances and identities are examples only; no real funds move here. Never send tokens to this prototype. The website does not provide real custody or buyer protection.

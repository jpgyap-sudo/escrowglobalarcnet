# Your first protected agreement

Start here · 4 min · External references checked 2026-09-12.

Agree first. Fund second. Release only under the agreed rules. This build uses simulated escrow funds.

## 1. Choose a starting point

Buy a listed product, hire a service, accept a project offer, or create a private agreement with an existing counterparty.

## 2. Write a measurable agreement

Specify the goods or deliverables, quantities, acceptance tests, delivery deadline, inspection period and who covers shipping or revisions.

## 3. Confirm both parties

The seller accepts the exact agreement. Fixed buyer and seller identities determine every refund and payout. Never assume an unfunded milestone is protected.

## 4. Fund, deliver and inspect

In this build, the buyer funds the agreement’s selected demo USDT or USDC plus a 3% reserve. The pricing selector never changes an existing agreement’s asset. Use the delivery workflow, then approve only what meets the agreed checklist.

## 5. Resolve an issue

Try a revision, return request or signed amendment first. A formal dispute costs the initiator another non-refundable 5% of the held principal in that milestone. The review team can release or refund it, not redirect it.

## Important limitation

Escrow Global is a working local sandbox. It does not currently custody tokens or provide real buyer protection.

## References

This guide describes the Escrow Global sandbox, not a live escrow service.

# How to fund a deal safely

Payments · 3 min · External references checked 2026-09-12.

Use this checklist before approving any payment request. A wallet popup is a request for your approval, not proof that a deal is complete.

## 1. Read the agreement

Confirm the parties, item or service, amount, asset, deadline, acceptance checks and refund rules.

## 2. Use your own wallet

Only use a wallet you control. Check the address and network before continuing.

## 3. Read the payment screen

Make sure the amount, asset and recipient match the agreement. Stop if anything is unexpected.

## 4. Wait for the status

Do not rely on a screenshot or a message saying “paid.” Wait for the deal page to show the result.

## 5. Keep your receipt

Save the payment reference and contact support if the result is missing or does not match the agreement.

## Important limitation

This website is an interactive sandbox. Balances and identities are examples only; no real funds move here. The sandbox has no live wallet payment or real token movement.

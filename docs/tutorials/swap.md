# Swap into USDC or USDT with Jupiter

Payments · 3 min · External references checked 2026-09-12.

The Jupiter swap screen is separate from an Escrow Global deal. A swap changes assets in your wallet; it does not fund this sandbox.

## 1. Open Wallet → Swap

Read the warning before enabling the external Jupiter screen.

## 2. Connect a supported wallet

Use a wallet you control and check that it is on the intended network.

## 3. Review the quote

Check the input, output, price impact, fees and slippage before approving.

## 4. Approve only what you understand

Read the wallet request carefully and reject anything unexpected.

## 5. Check your wallet

Confirm the result in your wallet. A successful swap does not create an Escrow Global deposit.

## Important limitation

This website is an interactive sandbox. Balances and identities are examples only; no real funds move here. The external wallet tool may involve real assets. Use it only when you understand the transaction.

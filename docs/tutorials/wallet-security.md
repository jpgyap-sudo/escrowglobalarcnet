# Stay safe when approving a payment

Wallet safety · 3 min · External references checked 2026-09-12.

Treat every wallet request as a permission slip. Take a moment to check what you are approving.

## 1. Use a wallet you control

Escrow Global should never ask for recovery words, a private key or an unexplained password.

## 2. Check the network

Make sure the wallet is using the network and asset you intended.

## 3. Read the amount and recipient

Reject requests that show an unexpected amount, destination or approval.

## 4. Approve only the intended payment

Never sign a blank, rushed or unexplained request.

## 5. Disconnect when finished

Close unfamiliar wallet sessions and keep the payment reference if you need support.

## Important limitation

This website is an interactive sandbox. Balances and identities are examples only; no real funds move here. External wallet actions can involve real assets. Never approve a request you do not understand.

## References

This guide describes the Escrow Global sandbox, not a live escrow service.
